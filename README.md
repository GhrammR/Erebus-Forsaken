# Erebus Forsaken

A dark-fantasy Greek-mythology isometric ARPG. Solo development in Godot 4.
Targeting Steam Early Access when Act 1 is polished.

**Status:** Pre-alpha. Stage 0 (bootstrap) complete.

## Engine & language

- Godot 4 (GDScript)
- Target platform: Windows / Steam
- Mobile is not a current concern

## Project charter

All development is governed by `.agent_governance/`. Read
[`.agent_governance/CLAUDE.md`](.agent_governance/CLAUDE.md) before
contributing or directing AI tooling at this repo.

The Act 1 completion checklist lives at
[`.agent_governance/commands/act1-status.md`](.agent_governance/commands/act1-status.md).

## Running locally

1. Install Godot 4.3 or newer.
2. Open `project.godot` from the Godot project manager.
3. Press F5.
