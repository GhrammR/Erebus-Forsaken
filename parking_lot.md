# Parking Lot

and so they do not silently leak into active work. Items here move into
scope only via explicit user approval and only when an Act 1 item is
fully complete.

## Format

```
### <slug> — <one-line idea>
- Why parked: <reason>
- Earliest revisit: <act / milestone>
- Notes: <freeform>
```
